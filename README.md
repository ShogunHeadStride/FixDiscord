>
> Добавьте каталог zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Если вы понимаете, как настраивать исключения, лучше добавить исключение аккуратно. При отсутствии такой уверенности рекомендуется отключить детектирование PUA.

## ⚙️Установка и использование

1. Активируйте безопасный DNS (Secure DNS).
   * В Chrome включите "Использовать безопасный DNS" и укажите поставщика, отличного от "Поставщик по умолчанию".
   * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем пункт "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
   * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы — инструкция находится [здесь](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот способ рекомендуется.
   * Владельцам роутеров Keenetic нужно включить в настройках параметр "Транзит запросов". При его отключении Secure DNS на компьютере может работать некорректно.

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/ShogunHeadStride/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и включите параметр "Разблокировать". Для архивов, открываемых через 7-Zip или PeaZip, этот шаг обычно не требуется.

4. Распакуйте файлы в каталог, путь к которому не содержит кириллицу и специальные символы.

5. Запустите подходящий файл.
   * Для поиска рабочей стратегии: **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`.
   * Для добавления стратегии в автозапуск: **`service.bat`** → `Install Service` → выберите нужную стратегию.

## ℹ️Назначение файлов и пунктов меню

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества факторов, поэтому **перебирайте стратегии, включая ALT, FAKE и другие, пока не найдёте подходящую для себя**.

- [**`service.bat`**](./service.bat) — установка автозапуска и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск через services.msc.</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб.
  - **`Check Status`** — посмотреть состояние обхода и служб, включая стратегию из автозапуска и WinDivert.
  - **`Game Filter`** — изменить режим обхода для игр и других программ, использующих UDP и TCP-порты выше 1023.  
    **После изменения параметра стратегию необходимо перезапустить.**  
    Значение в скобках показывает, включена функция или выключена.
  - **`IPSet Filter`** — переключить обработку сервисов из `ipset-all.txt`.  
    Этот параметр полезен при проверке ресурса, который без zapret работает, а с ним — нет.  
    В скобках отображается текущее состояние:
    - `none` — IP-адреса не проходят проверку;
    - `loaded` — адрес проверяется на наличие в списке;
    - `any` — под фильтр попадает любой IP-адрес.
  - **`Auto-Update Check`** — включить или отключить автоматический поиск обновлений.
  - **`Replace active fakes`** — заменить используемый фейк другим файлом из каталога `bin`.
  - **`Update IPSet List`** — получить актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновить hosts <ins>для восстановления веб-версии Telegram и подключения к голосовому чату Discord.</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений.
  - **`Run Diagnostics`** — проверить распространённые причины неисправности zapret.  
    В конце процедуры можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапного прекращения работы клиента.
  - **`Run Tests`** — запустить проверку стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`;
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️Частые вопросы и неисправности

### После запуска `general*` ничего не появляется

При запуске стратегии отдельным bat-файлом, а не через service, должен запуститься процесс winws.exe. Его можно увидеть на панели задач.  
Если процесс не появился, ознакомьтесь с [#522](https://github.com/ShogunHeadStride/zapret-discord-youtube/issues/522).

### Не удалось подобрать стратегию

- Откройте командную строку с правами администратора.
- По очереди выполните команды:

  `netsh winsock reset`

  `netsh int ip reset all`

  `netsh winhttp reset proxy`

  `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не открывается Telegram в браузере

Запустите **`service.bat`** и выберите **`Update hosts file`**. Если файл hosts устарел, программа предложит обновить его вручную:  
- Скопируйте весь текст из открывшегося блокнота.
- В появившейся папке откройте файл `hosts` в текстовом редакторе, запущенном от имени администратора.
- Вставьте скопированное содержимое в конец `hosts` или замените ранее добавленный аналогичный блок.
- Сохраните файл и снова проверьте подключение. Если результата нет, убедитесь, что изменения действительно сохранены.

#### Работа этого способа не гарантируется. Если он не помог, используйте [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) вместе с [локальным прокси](https://github.com/ShogunHeadStride/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Вариант, который некоторое время работал, может перестать подходить после его обнаружения.
> Здесь доступно много стратегий обхода. Если готовые варианты не помогают, создайте новую стратегию на основе одной из существующих и измените её параметры.
> Описание параметров находится [в документации](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте `service.bat` → `Run Diagnostics` и устраните найденные ошибки.
- Убедитесь, что адрес нужного ресурса присутствует в списках доменов или IP-адресов.
- Попробуйте другие варианты, в том числе **`ALT`** и **`FAKE`**.
- Выполните полную переустановку по инструкции ниже.
- См. [#765](https://github.com/ShogunHeadStride/zapret-discord-youtube/issues/765).

### Как полностью обновить или переустановить проект?

- Сохраните добавленные вами ресурсы и данные.
- Перезапустите устройство.
- Выполните `service.bat` → `Remove Services`.
- Запустите `service.bat` → `Run Diagnostics`; при наличии ошибок исправьте их, затем в конце выберите Y.
- Удалите каталог zapret.
- Скачайте свежую версию (`zapret-discord-youtube-...`) со [страницы релизов](https://github.com/ShogunHeadStride/zapret-discord-youtube/releases).
- Откройте свойства архива правой кнопкой мыши. Если внизу есть пункт разблокировки, включите его, нажмите применить и подтвердите изменения.
- Распакуйте архив в новый каталог в корне диска, без пробелов и специальных символов в пути.
- Запускайте разные скрипты `general` и проверяйте ресурсы. Если интернет-сервисы не открываются, закройте программу через значок замка на панели задач и попробуйте другую стратегию.
- После нахождения рабочего варианта добавьте его в автозапуск через `service.bat` → `Install Service`.

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остался среди служб

1. Узнайте имя службы в командной строке Windows. Нажмите Win+R, введите `cmd`, затем выполните:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fустановка-и-использование).
- Отключите блокировщик рекламы: известно, что YouTube начал активно бороться с такими расширениями.
- Переберите остальные стратегии, особенно если прежняя недавно перестала работать.
- См. также [#251](https://github.com/ShogunHeadStride/zapret-discord-youtube/discussions/251).

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fустановка-и-использование).
- Сначала определите стратегию, с которой открывается YouTube, и запустите её.
- Откройте `service.bat` → `Run Diagnostics` и очистите кэш Discord.
- Проверьте приложение Discord после очистки кэша.
- Откройте Discord в браузере по адресу https://discord.com/app. Если веб-версия работает, её можно использовать.
- Если браузерная версия тоже недоступна, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/ShogunHeadStride/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Используйте [tg-ws-proxy](https://github.com/ShogunHeadStride/tg-ws-proxy).
- Также можно воспользоваться бесплатными MTProto-прокси из интернета.

### Не работают игры

Игры используют разные настройки, поэтому проверить и исправить каждую из них невозможно.

Попробуйте универсальный порядок действий:
- обновите ipset через `service.bat` и включите `Game Filter`;
- если это не помогло, дополнительно активируйте `ipset any`.

У режима `ipset any` есть побочный эффект: многие сайты могут перестать открываться. Не держите этот режим включённым постоянно. Вместо этого определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`.

Если проблема сохранится, создайте обсуждение в разделе [Discussions](https://github.com/ShogunHeadStride/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет моей проблемы

- Создайте обращение [здесь](https://github.com/ShogunHeadStride/zapret-discord-youtube/issues).

## 🗒️Добавление адресов других ресурсов

Список ресурсов для обхода можно дополнить следующими файлами:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** — домены-исключения, например когда IP сети присутствует в `ipset-all.txt`, но конкретный домен фильтровать не нужно;
- **`ipset-all.txt`** — IP-адреса и подсети;
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые нужно исключить.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
